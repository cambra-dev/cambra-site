What the program does

Three filters narrow price_updates() to the tracked tickers. Each writes a Mut(Int, Txn) slot inside a transaction; a reader per ticker takes the latest price and quantity and feeds a line out. The greyed products still reach the program — the filter rejecting them is the thing worth seeing.

What the page does

Divides by the price scale and formats. Prices cross as integers of dollars × 10⁸, so nothing in the program is fractional. The one figure the page computes is the subtotal — three additions — because a block reading all six slots costs about two seconds per row against twenty-two milliseconds for the three readers here.

Not in this build

The live Coinbase socket. This page runs where a socket to another host is not permitted, so the toggle is absent rather than present and dead. Everything else — the compiler, the program, the inspector — is the same as the deck runs.
